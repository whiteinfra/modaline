# Чекліст приймання фічі (Acceptance Checklist)

Фіча: `feature/<назва>` · Історія/задача: `#<номер>` · Відповідальний: `<ім’я>`

## Функціональність
- [ ] Функція зроблена згідно ТЗ (номер вимоги FR-__ вказано в PR)
- [ ] Виконано всі критерії приймання користувацької історії
- [ ] Перевірено негативні сценарії (порожні поля, некоректні дані, відсутність прав)

## Якість коду
- [ ] Проведено code review (мінімум 1 approve)
- [ ] Код відповідає стилю проєкту (linters без помилок)
- [ ] Немає секретів/паролів у коді та історії комітів

## Тестування
- [ ] Юніт-тести — пройдено
- [ ] Integration-тести — пройдено
- [ ] CI-конвеєр зелений для останнього коміту гілки

## Документація
- [ ] Задокументовано API (ендпоінти, параметри, приклади)
- [ ] Оновлено README (якщо змінилось встановлення/запуск)
- [ ] Оновлено CHANGELOG і RELEASE NOTES (розділ `[Unreleased]`)

## Злиття
- [ ] Повідомлення комітів відповідають Conventional Commits
- [ ] Гілку злито в `develop` через `git merge --no-ff`
- [ ] Feature-гілку видалено після злиття
